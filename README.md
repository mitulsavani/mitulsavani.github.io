# mitulsavani.com

Personal website of Mitul Savani — Technical Lead at [HuLoop Automation](https://huloop.ai).

A single-page static site: plain HTML and CSS, no build step, no dependencies. Hosted on GitHub Pages with a custom domain (see `CNAME`).

## Files

- `index.html` / `index.css` — the site
- `profile.jpg` — headshot (portrait and favicon)
- `clarytyposter.pdf` — Claryty research poster, linked from the Research section

## Theme

The site follows the visitor's system light/dark preference by default. The switch in the top-right corner (system / light / dark) overrides it, persisted per device in `localStorage`.
